# Sai Xerox & Stationers Website

A responsive single-page website for Sai Xerox & Stationers, Tukum, Chandrapur.

## Files
- index.html — website
- styles.css — design and responsive layout
- script.js — small interactive enhancement
- logo.webp — supplied shop logo

## How to use
Open `index.html` in a browser to preview the website.

For publishing, upload all files together to any static website host. The WhatsApp, phone and Google Maps buttons are already configured with the shop details supplied by the owner.
